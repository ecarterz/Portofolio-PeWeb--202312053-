**Portofolio Pemrograman Web 2023**
Ini adalah repositori untuk proyek-proyek yang dikembangkan selama kursus Pemrograman Web. Repositori ini berisi kumpulan modul, yang masing-masing menunjukkan konsep dan teknologi yang berbeda yang dipelajari selama kursus.

**Deskripsi**
Proyek ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Web. Setiap modul dalam repositori ini mewakili topik atau tugas tertentu, yang mencakup berbagai teknologi mulai dari HTML dan CSS dasar hingga JavaScript dan framework yang lebih canggih.

**Daftar Isi**
Berikut adalah daftar semua modul yang tersedia di repositori ini. Klik pada setiap tautan untuk melihat kode sumber dan detail untuk setiap modul.

**Cara Menggunakan**
Salin Repositori:

git clone https://github.com/ecarterz/Portofolio-PeWeb--202312053-.git
Navigasi ke Folder Proyek:

cd Portofolio-PeWeb--202312053-

**Buka Modul:**
Pilih folder modul yang ingin Anda lihat.
Setiap folder berisi file index.html yang dapat Anda buka di browser untuk melihat hasilnya.
